# Changelog

## [0.3.0] - 2026-10-10

- added support for fallback-handlers through `App.fallback`
- removed support for handler-method overrides in `App.register`

## [0.2.0] - 2026-10-09

- add hooks for app startup and shutdown
- add support for `App` instances and factories in `runner.run_dev` (instead of only import path)

## [0.1.0] - 2026-10-01

- initial release
